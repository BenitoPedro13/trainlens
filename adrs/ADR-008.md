# ADR-008: Charts & Visualization: Recharts + D3 (Selective)

> **Status:** Accepted
> **Date:** 2026-05-19

## Context

The platform is heavily visualization-driven: training load charts, activity heatmaps, pace distributions, GPS overlays, and more. We need a charting strategy that covers standard chart types efficiently while allowing custom visualizations for unique analytics.

## Decision

Use **Recharts** as the default for standard charts (line, bar, area, pie, scatter). Use **D3.js** selectively for custom visualizations that Recharts can't handle.

## Options Considered

| Option | Recommendation |
|--------|----------------|
| **Recharts** ✅ (default) | Composable, React-native, good TypeScript support. Covers line, bar, area, pie, scatter |
| **D3.js** ✅ (selective) | For custom visualizations: heatmap calendar, GPS heatmap, performance management chart |
| **Visx** (Airbnb) | Good fallback if Recharts becomes limiting; more D3-like but React-wrapped |
| **Chart.js** | Avoid: imperative API, not React-idiomatic |
| **Plotly** | Avoid: too heavy, designed for data science notebooks, not web apps |

## Consequences

### Positive
- Recharts handles ~90% of charts with minimal code (declarative, composable)
- D3 provides full control for the remaining ~10% of custom visualizations
- Both are well-documented and have large communities
- Recharts components are easy to theme and make responsive

### Negative
- D3 visualizations require more effort and expertise to build and maintain
- Mixing two charting approaches means some inconsistency in how charts are authored

### Chart Assignments

| Chart Type | Library |
|------------|---------|
| Weekly volume bars | Recharts |
| CTL/ATL/TSB performance management chart | D3 (custom multi-line with zones) |
| Heart rate zone pie | Recharts |
| Activity heatmap calendar | D3 (custom grid layout) |
| Pace distribution histogram | Recharts |
| GPS activity heatmap | Leaflet/Mapbox + D3 overlay |
| Best efforts line chart | Recharts |
| Sport distribution donut | Recharts |
